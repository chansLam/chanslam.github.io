本次测试内容：★通话修复：电话走独立通话声道（不再被车机静音媒体通道影响），音乐/导航各有声。音频通道默认媒体5 / 导航10 / 通话0，设置页可调。热点/WiFi：切到热点自动开热点、另两tab自动开WiFi，热点名称/密码持久记录，连接方式保存重启记住。蓝牙：多台已连时优先识别 iPhone，状态卡显示开关状态，可一键开启。悬浮球取舍：只保留小白球并改为 DiPlay 图标样式。UI 美化：深蓝渐变背景 + 玻璃卡片 + 品牌区 + 状态徽章 + 连接中心横幅。系统设置：从设置面板移到应用列表「安卓设置」，ACTION_SETTINGS 失败走工程码 *#518200#* 保底。请重点验证：电话/音乐/导航是否有声；热点连接与 WiFi 直连；蓝牙设备显示；悬浮球；新 UI 观感。

安装说明：
1. 若装过其他签名版本，请先卸载旧版
2. APK 安装到车机（不是 iPhone）
3. 手机连上车机热点，保持蓝牙开启
4. 打开 DiPlay，点「连接手机」，iPhone 上允许 CarPlay
